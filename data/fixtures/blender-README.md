# Blender Open Data fixture

`blender.jsonl`: 17 real records, verbatim, from Blender Open Data's daily snapshot `opendata-2026-11-01` ([opendata.blender.org](https://opendata.blender.org), CC0). Three CUDA runs around the median for each of GTX 1650, RTX 2060, RTX 3060, RTX 3070 (in data/hardware.toml) and RTX 3050 (not in it), one OptiX run and one older-schema (v3) record that must be ignored.
